# Backend API Node.js

API REST desarrollada con **Node.js, Express y TypeScript**, orientada a la gestión de incidencias.
Proyecto creado como parte de mi aprendizaje y portafolio para postulación a cargos **Backend Developer**.

---

##  Tecnologías utilizadas

- Node.js
- Express
- TypeScript
- Prisma ORM
- PostgreSQL 
- dotenv
